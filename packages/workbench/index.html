fsio

a terminal running over your file system — no server, no sockets, just files in a folder

1Connect

This page talks to a small helper program by reading and writing files in a folder you both share. Nothing leaves your machine.

First, start the helper in a terminal (any folder works — this is an example):
npm run host -- ~/fsio-demo --allow-shell
Then pick that same folder here (or drag it onto this page):

2Check the speed

Sends 200 tiny messages through the folder and back, and times each round trip. This tells us whether a terminal over files can feel instant.
